CLM CRM Photo Migration Dry Run

This page changes nothing. It opens the CRM database read only and reports what a photo migration would do: how much space each package would save, and exactly which photos would move.

It shows counts, sizes and photo fingerprints only. No email text, contacts or photo content is displayed.

Close other CRM tabs first. On a large workspace this takes a minute.

What a migration would do, if you approve it later

Each photo stored as text inside a package would be stored once in the CRM photo store, with packages pointing at that one copy. Photos would be stored exactly as they are now, with no resizing or recompression, and identical photos would share a single copy.
