CLM CRM Claude Transfer Export

This page is read only. It exports the CRM data stored in this browser under the same GitHub Pages origin.

The export includes every IndexedDB record from the jn-agency-crm database, including workspace backups and media blobs converted to data URLs, plus CRM related localStorage values.

Chrome will ask where to save the file. Save it to your Downloads folder, not inside the CLM-CRM project folder, so it can never be uploaded to GitHub by mistake.

Security note

Gmail session tokens are intentionally not exported. Reconnect Gmail separately after transfer.
