CLM CRM Photo Migration

This moves each photo that is stored as text inside a package into the CRM photo store, and points the package at that one copy. Photos are stored exactly as they are: no resizing, no recompression, no change to which photo belongs to which model.

Run the dry run first and close every other CRM tab. Keep this tab open until it finishes.

Order of work: a full backup is written first, then photos are stored, then packages are updated, then every package is checked photo by photo. If any check fails, nothing is saved.

If anything goes wrong

Your packages are only overwritten at the very end, after every check has passed. The backup written at the start stays in the database under a key beginning before-photo-migration-, so the earlier state can always be read back.
