CLM CRM Photo Migration

This moves each photo that is stored as text inside a package into the CRM photo store, and points the package at that one copy. Photos are stored exactly as they are: no resizing, no recompression, no change to which photo belongs to which model.

Close every other CRM tab and keep this tab open until it finishes.

Order of work: the packages are backed up and converted and checked first, and only saved once every check passes. The package journal is then done the same way, separately, so the two are never held in memory together.

If anything goes wrong

Nothing is overwritten until every check has passed. The backup written at the start stays in the database under a key beginning before-photo-migration-, so the earlier state can always be read back.
